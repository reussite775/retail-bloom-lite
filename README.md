# Commerce Stream

Crée la base d'une application web de gestion de commerce de détail (SaaS) moderne et épurée, adaptée pour les commerçants. L'application doit contenir :

1. Un tableau de bord (Dashboard) affichant le chiffre d'affaires du jour et les statistiques de base.

2. Une gestion des produits et des stocks (ajouter, modifier, supprimer des articles avec prix d'achat, prix de vente et quantité en stock).

3. Une interface de caisse (Point de Vente) simple pour enregistrer les ventes du jour.

4. Un système de gestion d'essai gratuit de 7 jours pour les nouveaux utilisateurs, avec un écran de blocage clair une fois l'essai expiré si l'abonnement n'est pas actif.

Utilise un design professionnel et très lisible (vert et blanc/gris).
